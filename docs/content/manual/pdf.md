# Work through a PDF

A PDF opens in its own viewer, with what makes long documents manageable.

- **Outline** shows the PDF's own table of contents: choose an entry to go
  there.
- **Pages** lists every page, and marks the ones you wrote on with the tablet.
- **Page**: type a page number to go straight to it. Home and End go to the
  first and last page.
- **Select text** on the page, and **Copy selected text** puts it on the
  clipboard.
- **Find in this file** (Ctrl+F) searches the PDF's text.
- **Annotations** lists the layers of what you wrote on it with the tablet,
  above the PDF itself, to hide any of them.

The handwriting on a PDF is not searchable: the tablet only recognises
handwriting in notebooks.
