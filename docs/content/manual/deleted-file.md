# Get back a deleted file

Something deleted on the tablet or in the browser waits in the recycle bin
before it is removed for good. It keeps its place in your folders, so getting
it back puts it where it was, and on the tablet at its next sync. With
[Digest sync](@/manual/digest-sync.md) on, deleted digests wait there too.

1. Choose **Recycle bin** in the library's left rail. Deleted files are
   grouped by the day they were deleted, each with the days it has left.
2. Choose the file to look at it before you decide.
3. Choose **Restore**, in the file's own view or in its row's menu. A
   digest's menu says where it goes back: **Restore to** its category, which
   comes back with it if it was deleted too. A digest your tablet already sent
   back, because you had changed it there, can only be deleted for good: the
   copy in Digest is the one to keep.

![The recycle bin: deleted files grouped by the day they were deleted, each with a bar and the days it has left, and a menu at the end of each row.](screenshots/bin.png)

How long the bin keeps things is up to the household's administrator: 30 days
unless they [changed it](@/manual/quotas-and-bin.md).

## Delete for good

**Delete permanently**, in a row's menu, removes one file or digest now.
**Empty bin**, at the top, removes everything in it, digests included. Both ask
first, and neither can be undone.
