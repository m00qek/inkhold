# Keyboard shortcuts

## Reading a notebook or a PDF

| Keys | Does |
|---|---|
| <kbd>→</kbd> <kbd>←</kbd> | Next and previous page |
| <kbd>Home</kbd> <kbd>End</kbd> | First and last page |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> (<kbd>⌘</kbd>+<kbd>F</kbd> on a Mac) | Find in this note or file |
| <kbd>Enter</kbd>, <kbd>Shift</kbd>+<kbd>Enter</kbd> | In Find: the next and previous match |
| <kbd>Esc</kbd> | One thing at a time: a text selection in a PDF, then Find, then the notebook |

## To-Do

In a list, with a task selected:

| Keys | Does |
|---|---|
| <kbd>N</kbd> | New task |
| <kbd>↑</kbd> <kbd>↓</kbd> | Select the task above or below |
| <kbd>X</kbd> | Mark done |
| <kbd>E</kbd> | Rename |
| <kbd>M</kbd> | Move to another list |
| <kbd>D</kbd> | Set a date |
| <kbd>Alt</kbd>+<kbd>↑</kbd> <kbd>↓</kbd> | Reorder (not in **Planned** or **Completed**) |
| <kbd>Delete</kbd> | Delete |
| <kbd>Esc</kbd> | Let go of the task |

The same list is under **Keyboard shortcuts** on every To-Do page.
